# 0.3.2：状态优先的每日巡检通知

仅改变cards.py的展示逻辑，保留采集、分析、数据库、机柜映射和原始事件。默认消息不再展示正常机柜明细及冗长口径。

- 第一行和标题颜色直接显示：绿色正常、红色异常、橙色待确认。
- 保留GPU、PSU各自实际/预期数量。
- 正常时无机柜清单；异常或待确认时仅列相关机柜及原因。
- 正常需要数量匹配、设备级完整性证据、采样覆盖满足95%且查询完整。数据不足、查询失败、无有效数据、历史分类缺失显示待确认，不推算正常。
- 已确认问题与待确认同时存在时，顶部保守显示待确认，仍逐项列出已确认问题和数量。
- 仅表示监控采集状态，设备健康仍为未判定。没有引入AI或Web界面；完整明细保存在数据库，使用raw导出或API查询。
- 长消息仍按原字节上限拆卡，CLI预览与推送共用同一渲染器。

升级镜像：ghcr.io/hlqs-git/rackpulse:0.3.2。无需修改数据库或重采历史；生产升级由用户执行。
