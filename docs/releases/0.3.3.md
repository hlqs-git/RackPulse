# 0.3.3：异常原因聚合与简洁巡检通知

- 仅调整cards.py及相关测试，不改变采集、数据库结构、发送API、Webhook或签名实现。
- 标题和正文首项都显示正常/异常/待确认，保持绿色/红色/橙色。GPU、PSU各一行显示实际/预期/缺口；未知缺口为—，不把无数据当零。
- 问题按“判定类别+原因”聚合，使用机柜集合去重计数。历史不足、日报不完整等共性原因仅出现一次；查询失败、查询不完整和品牌冲突优先列出机柜名称，最多3个名称后注明总柜数。
- 最多5条详情；超过5类时显示前4类，第5条包含其余全部原因名称、各自涉及机柜数及剩余机柜去重数量。类型不会被静默丢弃；极端多种问题时该行可能换行较多。
- 正常机柜不出现，完整数据仍在数据库/API。监控采集状态与硬件健康严格分开，设备健康显示未判定。
- 合成预览见0.3.3-preview.md：正常5行，共性异常9行，混合异常9行；手机实际换行受屏幕和字号影响。
- 不部署生产，不发送真实飞书通知。
